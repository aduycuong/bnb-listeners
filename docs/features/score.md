# Score

Rate each collected item for quality so research uses clean, relevant content — not noise, duplicates, or low-value posts.

## Multi-dimensional scoring

Each item is scored on more than one axis so quality is actionable, not a single opaque number:

- Source credibility
- Completeness
- Freshness
- Relevance to real estate and marketing
- Duplicate / near-duplicate status

## Quality-gated retrieval

Agents prefer high-quality content by default. Items below a quality threshold are excluded from research unless the agent (or a user) explicitly asks to include them.

## Deduplicate before use

The same story often appears on many sites. Near-duplicates are merged or linked before tagging and trend counts, so copies do not inflate quality signals.

## Quality-aware trends

“Hot this month / this year” is based on volume, recency, and quality together. A cluster of low-quality social posts should not outrank a smaller set of strong industry articles.
