# Overview

This product collects, scores, and classifies content for real estate and marketing research.

It brings in website pages, blogs, news, social posts, and similar sources through internal tools and external services. Each item is stored in a common format, scored for quality, and classified into terms so research AI agents can work from a clean, relevant knowledge base.

Agents can then:

- Filter content by term
- Pull term insights
- Surface current trends and hot terms by month or year

## How it works

1. **Collect** — Periodically ingest raw content from many sources into one unified dataset.
2. **Score** — Rate each item for quality so low-value, duplicate, or noisy content can be filtered out.
3. **Classify** — Assign each item to existing terms, or auto-create a new term when none match.
4. **Serve** — Let research AI agents search, filter, and read the scored, classified content.
